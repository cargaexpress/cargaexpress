# Carriers and formats

The 5 Type A carriers send the same kind of information, but each one uses its own **format**, its own **field names** and
its own way of writing the **timestamp**.

| Carrier | Identifier | Format | Content-Type | Timestamp |
|---|---|---|---|---|
| SimCarrier Alpha | `alpha` | Flat JSON (snake_case) | `application/json` | ISO-8601 in UTC |
| SimCarrier Beta | `beta` | Nested JSON (camelCase) | `application/json` | Milliseconds since 1970 |
| SimCarrier Gamma | `gamma` | Spanish-language JSON | `application/json; charset=utf-8` | ISO-8601 in Colombian time (-05:00) |
| SimCarrier Delta | `delta` | XML | `application/xml` | `YYYYMMDDTHHMMSSZ` |
| SimCarrier Epsilon | `epsilon` | Form data | `application/x-www-form-urlencoded` | Seconds since 1970 |

## Real message examples

Generated by the simulator (simulated data). Gamma deliberately uses Spanish field names and values, because that is the
format it simulates.

### Alpha

```json
{"event_id": "92edcf45-1a1a-4e87-8b33-e968617959ce", "tracking_number": "ALP8480918169", "status": "IN_TRANSIT", "occurred_at": "2026-10-13T03:21:00Z", "location": "Bogotá"}
```

### Beta

```json
{"eventId": "ef901b93-2a7c-4880-aa37-53915c76f18a", "shipment": {"trackingId": "BET5219466551"}, "event": {"code": "300", "occurredAtEpochMs": 1791867840000}, "hub": "Cartagena"}
```

### Gamma

```json
{"id_evento": "f486ab73-9fab-4827-ae50-bd4eb52fa53c", "guia": "GAM2356321087", "estado": "En tránsito", "fecha": "2026-10-13T01:28:00-05:00", "ciudad": "Medellín"}
```

### Delta

```xml
<?xml version='1.0' encoding='utf-8'?>
<ShipmentEvent id="14b9adb5-0c6d-4a3d-b85a-5cd22959fea3"><Tracking>DEL7918451614</Tracking><Status>HUB</Status><Timestamp>20261013T030200Z</Timestamp><Location>Bogotá</Location></ShipmentEvent>
```

### Epsilon

```text
evt=85ae8770-f9db-41db-ab56-955dda2d3b3d&awb=EPS1889315464&state=Arrived+at+destination+facility&ts=1791856140&city=C%C3%BAcuta
```

## What each message contains

All five formats carry the same underlying information:

| Data | Purpose |
|---|---|
| Event identifier | Lets you detect duplicates: a resend carries the **same** identifier |
| Tracking number | Links all the events of a single shipment |
| Carrier's own status | Translated to the canonical status through the status mapping |
| Event date and time | Lets you sort events that arrive out of order |
| City or hub | Where the event happened |
